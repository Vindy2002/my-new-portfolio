# Vindya – Portfolio

## Run it
1. Install Node.js (version 18 or newer) from https://nodejs.org
2. Open a terminal in this folder and run:

    npm install
    npm run dev

3. Open the link it prints (usually http://localhost:5173)

## Build for hosting
    npm run build

The finished site is in the `dist` folder. Upload it to Netlify, Vercel or GitHub Pages.

## Edit your details
Open `src/App.jsx`. The `ME`, `PROJECTS` and `JOBS` blocks at the top hold your name, links, projects, skills and education.
Colors are the variables at the top of `src/index.css`.

## Your CV
The Download CV button gives `public/Nayomi_Vindya_CV.pdf`. Replace that file to update your CV.
